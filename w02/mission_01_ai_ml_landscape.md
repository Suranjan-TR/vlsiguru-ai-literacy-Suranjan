**Important:** This is a simplified concept map. Deep Learning is a type of Machine Learning. Generative AI describes systems that generate new content, while LLMs are models designed for language tasks. Generative AI and LLMs should not be treated as strict levels below Deep Learning.

## 2. Five Important Distinctions

### 1. AI vs Rule-Based Programming

AI is the broad field of creating systems that perform tasks associated with intelligent behaviour. Rule-based programming follows instructions explicitly written by a programmer.

**Example:** A program that displays a warning when the temperature exceeds 80°C follows a predefined rule.

### 2. AI vs Machine Learning

AI is the broader field, while Machine Learning is one approach within AI. Machine Learning systems learn patterns from data and use them to make predictions or decisions.

**Example:** An email spam filter can learn patterns from previous emails to classify new messages.

### 3. Machine Learning vs Deep Learning

Machine Learning includes different methods for learning patterns from data. Deep Learning is a type of Machine Learning that uses neural networks with multiple layers.

**Example:** A deep-learning model can learn patterns to recognise objects in images.

### 4. Deep Learning vs Generative AI

Deep Learning describes a family of machine-learning methods, whereas Generative AI describes systems that generate new content, such as text, images, audio or code.

Many modern Generative AI systems use deep-learning models, but Generative AI is not simply another level below Deep Learning.

### 5. Generative AI vs Large Language Models

Generative AI includes systems that generate different types of content. Large Language Models (LLMs) are designed to process and generate language.

**Example:** ChatGPT can generate a written explanation, while an image-generation system can create an image from a text description.

## 3. Why Automation Is Not Necessarily AI

Automation means using technology to perform tasks with less manual effort. A task can be automated using fixed rules without learning from data.

**Example:** A fan that turns on automatically when the temperature exceeds a fixed threshold uses rule-based automation.

Therefore, automation does not automatically mean AI or Machine Learning.

## 4. Why AI Does Not Always Mean Machine Learning

AI is a broad field that includes different approaches. Some systems use Machine Learning, while others use explicitly programmed rules.

**Example:** A rule-based expert system can make decisions by following predefined conditions without learning patterns from data.

Therefore, not every AI system must use Machine Learning.

Other Methods That Make Up AI (Without ML)

• Rule-Based Systems (Expert Systems): Programs built on explicit "If-Then" logic rules created by human experts (such as early medical diagnostic tools or chess engines using hardcoded decision trees).
• Symbolic AI (Good Old-Fashioned AI / GOFAI): Systems that manipulate symbols, logic, and abstract concepts rather than learning statistical patterns from data.
• Search and Optimization Algorithms: Algorithms that explore all possible paths to solve a problem (like pathfinding in GPS or solving puzzles) using logic rather than training on data.
• Hardcoded Robotics and Control Logic: Traditional automated systems that follow fixed operational scripts to perform repetitive physical tasks.

## 5. What Is Explicitly Programmed and What Is Learned?

| Aspect | Rule-Based Programming | Machine Learning |
|---|---|---|
| How it works | Follows rules explicitly written by a programmer. | Learns patterns from training data. |
| Source of behaviour | Programmed instructions and conditions. | Patterns represented by a trained model. |
| Example | If temperature > 80°C, display WARNING. | Learn from historical measurements to predict overheating. |
| Limitation | Fixed rules may not handle every situation. | Performance depends on data quality and model suitability. |

## 6. Three Examples with Classification

| Example | Classification | Reason |
|---|---|---|
| Calculator performing multiplication | Traditional software | It follows programmed mathematical procedures. |
| Email spam filter trained on labelled emails | Machine Learning-based AI | It learns patterns from examples to classify new emails. |
| ChatGPT generating an explanation | Generative AI | It generates new text based on the prompt and available context. |
