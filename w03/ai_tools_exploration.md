
# AI Tools Exploration

## 1. Objective

The objective of this mission is to explore AI tools for technical learning, improve prompts, compare explanations, and verify important information using reliable sources.

## 2. AI Tools Explored

| AI Tool | Purpose |
|---|---|
| ChatGPT | Understanding machine learning concepts through simple explanations and examples. |
| Google Gemini | Comparing explanations of technical concepts with another AI tool. |
| Perplexity | Finding technical information and source links for further verification. |

## 3. Prompt Improvement

### Initial Prompt

Explain machine learning.

### Improved Prompt

I am an Electronics and Communication Engineering graduate learning AI and VLSI Design Verification. Explain supervised, unsupervised, semi-supervised, self-supervised, and reinforcement learning in simple language. Compare them in a table and provide one example for each approach.

### Observation

The improved prompt provides my background, specifies the topics, and requests a clear output format. This makes the response more relevant and easier to understand.

## 4. Comparison of AI Tools

**Question:** What is the difference between supervised and unsupervised learning?

I used ChatGPT to understand the concepts and compared its explanation with Google Gemini.

| Comparison point | Observation |
|---|---|
| Explanation | Both tools can explain the basic concepts using examples. |
| Usefulness | Simple examples and comparisons help beginners understand unfamiliar topics. |
| Verification | Similar answers from two AI tools do not guarantee correctness. Important claims should be checked against reliable sources. |

## 5. Verification of an AI Claim

**Claim:** Supervised learning uses labelled examples to learn from inputs and their corresponding target values.

**Source:** Google Developers — Introduction to Machine Learning

https://developers.google.com/machine-learning/intro-to-ml

**Verification:** I checked the source's explanation of supervised learning and compared it with the claim.

**Conclusion:** The source supports the basic definition of supervised learning as learning from labelled examples. This confirms the main claim, but other technical details require their own verification.

## 6. Testing My Understanding

AI tools can also be used to check understanding through questions and follow-up explanations.

Examples of questions:

- What is the difference between precision and recall?
- Why can a model have high accuracy but low recall?
- How does semi-supervised learning differ from self-supervised learning?
- How might machine learning support engineering tasks?

Answering these questions helps identify concepts that need further study.

## 7. Responsible Use

- Verify important claims using reliable sources, especially official documentation.
- Review and test AI-generated code before using it.
- Do not upload confidential RTL, netlists, timing constraints, or proprietary design data to public AI tools.
- Ensure that submitted work reflects my own understanding.

## Conclusion

AI tools can support technical learning by explaining concepts, providing examples, comparing approaches, and helping identify knowledge gaps. Clear prompts and independent source verification improve the usefulness and reliability of AI-assisted learning.
